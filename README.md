This repository contains my practice work focused on improving data analytics and problem-solving skills through SQL, Python, and Statistics.

## Overview
I regularly practice interview-style questions to strengthen my understanding of:
- SQL querying and data manipulation
- Python for data analysis
- Statistical concepts and hypothesis testing
- Exploratory Data Analysis (EDA)

- Statistical inference and comparisons

To build strong foundations in data analytics and prepare for data analyst / data scientist interviews by solving real-world style problems.

## Tools Used
