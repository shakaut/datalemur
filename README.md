# Data Analytics Practice (SQL, Python & Statistics)

This repository contains my practice work focused on improving data analytics and problem-solving skills through SQL, Python and Statistics.

## Overview
I regularly practice interview-style questions to strengthen my understanding of:
- SQL querying and data manipulation
- Python for data analysis
- Statistical concepts and hypothesis testing
- Exploratory Data Analysis (EDA)

## Skills Practiced
- SQL: SELECT, JOINs, GROUP BY, Window Functions, CTEs
- Python: Data cleaning, pandas operations, basic analysis
- Statistics: Descriptive statistics, probability, hypothesis testing
- Problem Solving: Business-oriented data analysis questions

## Topics Covered
- Data aggregation and summarization
- Time-based analysis
- Ranking and window functions
- Dataset filtering and transformation
- Statistical inference and comparisons

## Goal
To build strong foundations in data analytics and prepare for data analyst / data scientist interviews by solving real-world style problems.

## Tools Used
- SQL
- Python (pandas, numpy)
- Statistics fundamentals

Actively practicing and updating this repository with new problems and solutions.
